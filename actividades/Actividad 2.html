Código


    #include <stdio.h>>
    int main() {
    int edad;
    printf("¿Cuántos años tienes? ");
    scanf("%d", &edad); 
    if (edad >= 18) {
        printf("Eres mayor de edad.\n");

    } else {

        printf("Eres menor de edad.\n");

    }
    return 0;
    }

Explicación del código en general

Este código en C pide la edad del usuario y depúes verifica si es mayor o menor de edad usando la condición de if.

Explicación línea por línea

La línea int main() es la función principal donde inicia el programa.

La línea int edad; declara una variable llamada edad.

La línea printf("¿Cuántos años tienes? "); muestra una pregunta en pantalla.

La línea scanf("%d", &edad); guarda la edad que escribe el usuario.

La línea if (edad >= 18) verifica si la edad es mayor o igual a 18.

La línea printf("Eres mayor de edad.\n"); manda el mesanje si el usuario tiene 18 o más.

La línea else se ejecuta cuando la condición no se cumple.

La línea printf("Eres menor de edad.\n"); muestra que el usuario es menor de edad porque no cumple con la condición de tener 18 o más.

La línea return 0; indica que el programa terminó correctamente.
