Tabla de apunte
Etiqueta Para que sirve Ejemplo mínimo
ol Es una lista ordenada 

            <ol>
                <li>Elemento 1</li>
                <li>Elemto 2</li>
                <li>Elemto 3</li>
            </ol>
ul Es una lista desordenada 

            <ul>
                <li>Lunes: 10:20 - 12:00</li>
                <li>Martes y Jueves: 10:20 - 11:10</li>
            </ul>
code Para poner parte de un código 

            <code>int edad;</code>
p Es para poner un párrafo 

            <p>Sistema de inscripciones a talleres extrarriculares</p>
li Es para poner loes elementos de una lista 

            <li><a href="index.html">Inicio</a></li>
